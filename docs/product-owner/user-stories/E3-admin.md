# E3 管理

← [用户故事地图](../User-Story-Map.md)

## 背景

管理员在 Admin 维护商品、处理订单并管理用户，保证店铺可持续运营。

---

## US-07 维护商品

**As a** 管理员  
**I want** 在 Admin 创建或更新商品  
**So that** 店面展示反映最新目录

### 验收标准

1. **Scenario** 维护商品  
   **GIVEN** 管理员已登录 Admin  
   **WHEN** 创建或更新商品  
   **THEN** 店面 `/products` 展示反映变更

### 状态

已实现

---

## US-08 处理订单

**As a** 管理员  
**I want** 查看并更新订单状态  
**So that** 履约与客服可跟进顾客订单

### 验收标准

1. **Scenario** 订单列表  
   **GIVEN** 存在顾客订单  
   **WHEN** 打开 Admin 订单列表  
   **THEN** 可见状态与关键字段并可更新

### 状态

已实现

---

## US-09 管理用户

**As a** 管理员  
**I want** 查看店铺用户账号  
**So that** 我可以支持账号问题与权限治理

### 验收标准

1. **Scenario** 用户列表  
   **GIVEN** 管理员已登录 Admin  
   **WHEN** 打开用户管理  
   **THEN** 可见注册用户的关键摘要

### 状态

已实现
